# PeopleSoft Enrolment Questions - Translated

A one-page translation guide for teachers enrolling AMEP / SEE students in PeopleSoft.

It has the questions from the *PeopleSoft Enrolment Teacher Conversation Guide* (the tip boxes and the enrolment question tables) in 27 languages: Simplified Chinese, Korean, Japanese, Farsi, Arabic, Spanish, Thai, Tamil, Vietnamese, Ukrainian, Russian, Nepali, Burmese, Turkish, Indonesian, Punjabi, Dari, Portuguese, Khmer, Mongolian, Pashto, Urdu, Hindi, Kurdish (Kurmanji), Kurdish (Sorani), Tigrinya and Swahili.

- Pick the student's language at the top of the page.
- **Show** fills the screen with the translation so you can turn it to the student.
- **Copy** copies the translation.
- **Print this language** prints every question as a table for the selected language (A4, with the language in the top-right corner of each page).

Open `index.html` in a browser, or view it on GitHub Pages.

Translations have not yet been checked by native speakers. Please review before use.

## Student guide

`students/index.html` is a student version of the guide, in the same 27 languages plus English. Students choose their language and see what to bring, the questions their teacher will ask, and what happens after enrolment. Each line shows the translation with the English underneath, and a 🔊 button plays the English so students can hear how the teacher will say it.

Link students straight to their language with `?lang=` and a code, for example `students/?lang=ar` or `students/?lang=zh`.
