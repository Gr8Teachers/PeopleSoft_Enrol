# PeopleSoft Enrolment Phrasebook

A one-page phrasebook for teachers enrolling AMEP / SEE students in PeopleSoft.

It has the questions from the *PeopleSoft Enrolment Teacher Conversation Guide* (the tip boxes and the enrolment question tables) in 12 languages: Simplified Chinese, Korean, Japanese, Farsi, Spanish, Thai, Tamil, Vietnamese, Ukrainian, Russian, Nepali and Burmese.

- Pick the student's language at the top of the page.
- **Show** fills the screen with the translation so you can turn it to the student.
- **Copy** copies the translation.

Open `index.html` in a browser, or view it on GitHub Pages.

Translations have not yet been checked by native speakers. Please review before use.
